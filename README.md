# LOF 套利记账本（lof_trade_recorder）

场外申购 → 场内卖出的套利记账 GUI（Tkinter）。功能已定型，优先小修，勿在此目录塞大新功能。

## 启动

须在本目录下启动（相对路径读写 `data/`）：

```bash
conda activate funds
cd lof_trade_recorder
python main.py
```

解释器：`D:\Workspace\miniconda\envs\funds\python.exe`。数据：`data/{6位基金代码}.json`（契约见 [docs/data-schema.md](../docs/data-schema.md)）。

## 窗口总布局

```text
┌─────────────────────────────────────────────────────────────┐
│  Notebook 标签栏（每只基金一个 Tab，标题=基金代码或 Sheet N）   │
├─────────────────────────────────────────────────────────────┤
│  【当前 Tab = TradeSheet】                                    │
│  ┌─ top_info_bar ─────────────────────────────────────────┐ │
│  │ 基金名称|名称|当前时间|当前场内价格|价格|涨跌幅|QDII勾选 │ │
│  └────────────────────────────────────────────────────────┘ │
│  ┌─ 可滚动表格（canvas + scrollbar）──────────────────────┐ │
│  │ 10 列表头 + 数据行                                       │ │
│  └────────────────────────────────────────────────────────┘ │
│  ┌─ button_bar ───────────────────────────────────────────┐ │
│  │ 顶部插入 | 底部追加 | 删除选中行 | 刷新利润/涨幅 [|更多] │ │
│  └────────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────────┤
│  全局 control_frame：[+ 记录新基金交易] [- 删除当前基金表单]   │
└─────────────────────────────────────────────────────────────┘
```

- 默认窗口约 `1400×600`，最小约 `1300×500`（见 `table_manager.py`）。
- 表格在 canvas 内滚动；底栏按钮固定在 Tab 内、不进 grid，避免与数据行抢行号。

## 顶部信息条（top_info_bar）

| 列 | 控件 | 内容 |
|----|------|------|
| 0 | Label | `基金名称` |
| 1 | Entry | 基金中文名（蓝字） |
| 2 | Entry（只读） | 当前时间，约每分钟刷新，`yyyy-mm-dd HH:MM` |
| 3 | Label | `当前场内价格` |
| 4 | Entry | 实时价（蓝字，约每 5 秒刷新；固定 **3** 位小数） |
| 5 | Entry | 涨跌幅 `%`（红涨绿跌） |
| 6 | Checkbutton | `QDII（T+2确认）`；勾选后确认日按 T+2，写入 `top_info.is_qdii` |

## 数据表（table_frame）

- Grid：`row 0` = 表头；`row 1+` = 数据（`DATA_GRID_OFFSET = 1`）。
- 共 **10** 列；旧 6～9 列 JSON 加载时自动补齐/插入「买入份额」。

| 列 | 表头 | 说明 |
|----|------|------|
| 0 | 日期 | DateEntry；可编辑；新建行默认最新交易日（工作日，周末回退周五）；失焦/回车触发申购重算 |
| 1 | 净值 | 计算/本地填充 |
| 2 | 申购金额 | 可编辑；`0` 表示当日无申购（可仅记卖出） |
| 3 | 到账份额 | 申购计算填充；与买入/卖出独立 |
| 4 | 申购成本/份 | 计算/本地填充；固定 **3** 位小数（如 `1.870`） |
| 5 | 预估利润 | `(场内价 - 成本/份) × 到账份额 - 0.2`（按原申购份额，不按剩余持仓） |
| 6 | 至今涨幅 | `(当前场内价 - 当日净值) / 当日净值 × 100%` |
| 7 | 买入份额 | 该日买入份额（FIFO 批次）；可与申购并存。首次申购成功且此列为空/`0` 时用到账份额预填，之后不覆盖 |
| 8 | 卖出份额 | 该日卖出份额（默认 `0`）；FIFO 从更早确认批次扣减 |
| 9 | 满7日剩余 | 只读；处理完该日买卖后，剩余持仓中相对**今天**已满 7 自然日的份额 |

### 买卖与满 7 日规则

- **买入 / 卖出**：挂在行日期上；按日期排序后卖出 **FIFO** 扣减，买入按确认日登记新批次。
- **确认日**：普通基金 = 申购日 T 起第 1 个交易日（T+1）；QDII = 第 2 个交易日（T+2）。交易日仅跳过周六日，**不含法定节假日**。
- **满 7 日**：相对**当前日期（今天）**，`(今天 - 确认日).days >= 7`（自然日）；不是相对行日期。时钟约每分钟会重算一次。
- **同日既买入又卖出**：先卖出（只能吃已确认份额），再登记当日买入。
- 隐藏的历史行仍参与 FIFO / 满 7 日计算。

### 选中与编辑

- 单击：选中一行（浅蓝高亮）；Ctrl 多选；Shift 连选
- 「日期」「申购金额」失焦/回车：请求净值并重算申购；**不改卖出份额**；买入份额仅在为空/`0` 时用到账预填
- 申购金额 ≤0：清空「到账份额 / 申购成本/份」，**保留买入/卖出**；仍尽量拉取当日净值（供至今涨幅）
- 「买入份额」「卖出份额」失焦/回车：仅本地 FIFO 重算，不打净值接口
- 启动加载不批量打网，直接用本地 JSON；缺净值可失焦重算或点「刷新利润/涨幅」（后台补齐）
- `xalpha` 的 `fundinfo` 按基金代码缓存，避免每行重复拉全历史

### 历史折叠

- 默认按**当前表格可视高度**只显示能放下的行；放不下的自动收入「更多交易」（表序靠后的先藏）
- 窗口尚未布局完成时，先用 `FALLBACK_VISIBLE_ROWS`（8）切分，布局后再按真实高度调整
- 折叠态下新增行若超出容量，底部行自动收入「更多」；删行或拉高窗口时会从「更多」补回
- 点击「查看更多交易」后展开全部（可滚动），不再自动折叠
- 有隐藏数据时，底栏出现 `查看更多交易（N）`

## 底栏按钮（button_bar）

| 按钮 | 行为 |
|------|------|
| ↑ 顶部插入 ↑ | 在表顶插入一行；日期默认**最新交易日**（可改） |
| ↓ 底部追加 ↓ | 在表底追加一行；日期默认**最新交易日**（可改） |
| ✖ 删除选中行 ✖ | 删除全部选中行并保存 |
| 刷新利润/涨幅 | 先本地瞬间刷利润/涨幅/满7日；金额=0 只清空申购派生列（保留买入/卖出）；缺数时的净值/申购重算在后台进行 |
| 查看更多交易（N） | 仅有隐藏历史时显示 |

## 全局底栏（TableManager.control_frame）

| 按钮 | 行为 |
|------|------|
| + 记录新基金交易 | 新建 Tab |
| - 删除当前基金表单 | 删 Tab 及对应 `data/*.json` |

- 双击 Tab 标题：改为 6 位基金代码，并尝试拉取基金名 / 刷新价格
