# LOF 套利记账本（lof_trade_recorder）

场外申购 → 场内卖出的套利记账 GUI（Tkinter）。功能已定型，优先小修，勿在此目录塞大新功能。

给人看的操作步骤见 [使用说明.md](使用说明.md)。本文保留布局、列含义和改动约定。

## 启动

从零装 Python / 虚拟环境 / 依赖的步骤见 [使用说明.md](使用说明.md)。第三方包清单见本目录 [requirements.txt](requirements.txt)。须在本目录下启动（相对路径读写 `data/`）：

```bash
# 先激活你的虚拟环境，再：
python -m pip install -r requirements.txt
python main.py
```

数据：`data/{6位基金代码}.json`（契约见 [docs/data-schema.md](../docs/data-schema.md)）。

## 窗口总布局

```text
┌─────────────────────────────────────────────────────────────┐
│  Notebook 标签栏（每只基金一个 Tab，标题=基金代码或 Sheet N）   │
├─────────────────────────────────────────────────────────────┤
│  【当前 Tab = TradeSheet】                                    │
│  ┌─ top_info_bar ─────────────────────────────────────────┐ │
│  │ 基金名称|名称|当前时间|场内价格|价格|涨跌幅|QDII │ │
│  └────────────────────────────────────────────────────────┘ │
│  ┌─ 可滚动表格（canvas + scrollbar）──────────────────────┐ │
│  │ 10 列固定 + 赎回分段动态列                                │ │
│  └────────────────────────────────────────────────────────┘ │
│  ┌─ button_bar ───────────────────────────────────────────┐ │
│  │ 顶部插入 | 底部追加 | 删除选中行 | 刷新利润/涨幅 [|更多] │ │
│  └────────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────────┤
│  全局 control_frame：[+ 记录新基金交易] [- 删除当前基金表单]   │
└─────────────────────────────────────────────────────────────┘
```

- 默认窗口约 `1100×600`；宽度按表格实际需求自适应（顶栏已收紧，不再等宽撑开；见 `fit_window_to_active_sheet`）。
- 表格在 canvas 内滚动；底栏按钮固定在 Tab 内、不进 grid，避免与数据行抢行号。

## 顶部信息条（top_info_bar）

| 列 | 控件 | 内容 |
|----|------|------|
| 0 | Label | `基金名称` |
| 1 | Entry | 基金中文名（蓝字） |
| 2 | Entry（只读） | 当前时间，约每分钟刷新，`yyyy-mm-dd HH:MM` |
| 3 | Label | `场内价格` |
| 4 | Entry | 实时价（蓝字，约每 5 秒刷新；固定 **3** 位小数） |
| 5 | Entry | 涨跌幅 `%`（红涨绿跌） |
| 6 | Checkbutton | `QDII（T+2）`；勾选后确认日按 T+2，写入 `top_info.is_qdii` |

## 数据表（table_frame）

- Grid：`row 0` = 表头；`row 1+` = 数据（`DATA_GRID_OFFSET = 1`）。
- 每列宽度按该列表头的实际文字宽度自适应，保证标题完整显示；各列互不等宽。日期列同时容下 `yyyy-mm-dd`。
- 前 **10** 列固定；其后为按基金赎回费率分段的动态列（来自 xalpha `feeinfo`）。旧 JSON 没有「赎回份额」时按 0 补上，并丢掉旧分段尾列后重算。

| 列 | 表头 | 说明 |
|----|------|------|
| 0 | 日期 | DateEntry；可编辑；顶部插入默认「已有最近日期之后的最新交易日」（周末前进到下周一；不含法定节假日）；底部追加仍用当天回退周五的最新交易日；失焦/回车触发申购重算 |
| 1 | 净值 | 计算/本地填充 |
| 2 | 申购金额 | 可编辑；`0` 表示当日无申购（可仅记卖出）；标题可带实际佣金费率，如 `申购金额（0.12%）`。到账份额按公告费率外扣，佣金按标题费率 |
| 3 | 到账份额 | 申购计算填充；与买入/卖出/赎回独立 |
| 4 | 申购成本/份 | 计算/本地填充；固定 **3** 位小数（如 `1.870`） |
| 5 | 预估利润 | `(场内价 - 成本/份) × 到账份额 - 0.2`（按原申购份额，不按剩余持仓） |
| 6 | 至今涨幅 | `(当前场内价 - 当日净值) / 当日净值 × 100%` |
| 7 | 买入份额 | 场内买入份额（**T 日确认**）；可与申购并存。申购成功且此列为空/`0` 时用到账份额预填（仅展示，不重复计入持仓）；亦可只填买入、不填申购 |
| 8 | 卖出份额 | 场内卖出（**T 日**从已确认批次 FIFO 扣减；默认 `0`） |
| 9 | 赎回份额 | 场外赎回（**T+1 / QDII T+2** 确认后才扣减；默认 `0`）。确认前份额仍留在分段里 |
| 10… | 赎回分段 | 只读；表示**当前**剩余持仓分档（FIFO 一次重放全部流水后的结果），只写在日期最晚的那一行，其余行为 `-`。**当前持仓为 0 的档不显示** |

### 四个操作与赎回分段

剩余分段只看**今天已经生效**的批次。确认日未到的增加不入账，确认日未到的赎回也不扣减。交易日只跳过周六日，**不含法定节假日**。QDII 勾选后，申购和赎回的确认日都是 T+2，否则 T+1。

| 操作 | 列 | 对持仓 | 生效日 |
|------|----|--------|--------|
| 申购 | 到账份额 | 增加 | T+1 / T+2，持有天数从这一天起算 |
| 买入 | 买入份额 | 增加 | 行日期 T，当日起算。同日已有到账时只计「买入 − 到账」 |
| 卖出 | 卖出份额 | 减少 | 行日期 T，只扣当时已经确认的批次 |
| 赎回 | 赎回份额 | 减少 | T+1 / T+2；确认前仍出现在分段列里 |

- 同一生效日、同一行：先扣减（卖出，或当天确认的赎回），再登记当天确认的买入和申购。
- 更早一行里、恰好在这一天确认的申购，可以被这一天的卖出或赎回扣到。
- 分段列相对**今天**按 `今天 − 确认日` 分档；计算会读全部历史流水，但结果只落到最晚一行（不必每行存一份中间状态）。时钟约每分钟重算一次。
- 隐藏的历史行仍参与 FIFO，不参与分段列展示。

### 选中与编辑

- 单击：选中一行（浅蓝高亮）；Ctrl 多选；Shift 连选
- 「日期」「申购金额」失焦/回车：请求净值并重算申购；**不改卖出/赎回份额**；买入份额仅在为空/`0` 时用到账预填
- 申购金额 ≤0：清空「到账份额 / 申购成本/份」，**保留买入/卖出/赎回**；仍尽量拉取当日净值（供至今涨幅）
- 「买入份额」「卖出份额」「赎回份额」失焦/回车：仅本地 FIFO 重算，不打净值接口
- 启动先读本地 JSON；窗口就绪后对空着的净值/到账/成本自动补算。点「刷新利润/涨幅」同样默认只补空，并本地重刷利润/涨幅/分段；要按新公式重算已有申购时，改该行日期或金额即可
- `xalpha` 的 `fundinfo` 按基金代码缓存，避免每行重复拉全历史

### 历史折叠

- 默认按**当前表格可视高度**只显示能放下的行；放不下的自动收入「更多交易」（表序靠后的先藏）
- 窗口尚未布局完成时，先用 `FALLBACK_VISIBLE_ROWS`（8）切分，布局后再按真实高度调整
- 折叠态下新增行若超出容量，底部行自动收入「更多」；删行或拉高窗口时会从「更多」补回
- 点击「查看更多交易」后展开全部（可滚动），不再自动折叠
- 有隐藏数据时，底栏出现 `查看更多交易（N）`

## 底栏按钮（button_bar）

| 按钮 | 行为 |
|------|------|
| ↑ 顶部插入 ↑ | 在表顶插入一行；日期默认已有条目最近日期之后的最新交易日（周末则用即将到来的周一；可改） |
| ↓ 底部追加 ↓ | 在表底追加一行；日期默认当天最新交易日（周末回退周五；可改） |
| ✖ 删除选中行 ✖ | 删除全部选中行并保存 |
| 刷新利润/涨幅 | 本地刷利润/涨幅/赎回分段；后台只补空着的净值/到账/成本（不重打已填完整的历史申购） |
| 查看更多交易（N） | 仅有隐藏历史时显示 |

## 全局底栏（TableManager.control_frame）

| 按钮 | 行为 |
|------|------|
| + 记录新基金交易 | 新建 Tab |
| - 删除当前基金表单 | 删 Tab 及对应 `data/*.json` |

- 双击 Tab 标题：改为 6 位基金代码，并尝试拉取基金名、赎回分段列与场内价
